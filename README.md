# StudyMedSmart

نسخة MVP قابلة للنشر على Render: واجهة عربية RTL + Node/Express + PostgreSQL + تسجيل دخول + اشتراك شامل + رصيد + تقدم + اختبارات + لوحة إدارة API.

## Render
- Runtime: **Node**
- Branch: `main`
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables:
  - `DATABASE_URL` = **Internal Database URL** من قاعدة Render
  - `JWT_SECRET` = قيمة عشوائية طويلة
  - `ADMIN_EMAIL` = بريد المدير
  - `ADMIN_PASSWORD` = كلمة مرور المدير
- Health Check: `/healthz`

> لا تضع كلمة مرور قاعدة البيانات داخل GitHub. استخدم Environment Variables في Render.

## ما يعمل في النسخة الأولى
- الصفحة الرئيسية والكورسات وتفاصيل الكورس.
- الستة كورسات ليست hard-coded ويمكن إدارتها من قاعدة البيانات.
- الاشتراك واحد لجميع الكورسات وسعره من `site_settings`.
- الطالب يستطيع رؤية أسماء الدروس قبل الاشتراك، لكن المحتوى محمي بعد الاشتراك.
- كل درس يدعم Video URL + PDF URL + Quiz.
- الكويز: 4 اختيارات، إجابة صحيحة، شرح الإجابة، نسبة نجاح 50% افتراضياً.
- بعد الاختبار تظهر الإجابات الصحيحة والخاطئة والشرح.
- إكمال الدرس يُحتسب عند النجاح، والتقدم/المتوسط/آخر درس يتحدث من قاعدة البيانات.
- نظام wallet: الإدارة تضيف رصيداً، والاشتراك يخصم سعر الباقة مرة واحدة.

## ملاحظة
واجهة الإدارة الكاملة تحتاج صفحة `admin.html` في الخطوة التالية؛ الـAPI الإداري موجود بالفعل في `server.js`.
